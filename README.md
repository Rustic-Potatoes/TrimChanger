TrimChanger
=======

this plugin adds the trim command that allows players to remove the trim off of their armor. it also has other helpful functions, like being able to query what armor and trim a player is wearing. Most features are able to be configured depending on your needs.

right now it only supports paper servers and direct forks of it.

#### If you encounter any bugs or have a suggestion, please report it on my [GitHub page](https://github.com/Rustic-Potatoes/TrimChanger/).
